How to Join

1
Fork the acg-member-template — click "Use this template" on GitHub
2
Edit manifest.json with your handle, GitHub username, tagline
3
Deploy — enable GitHub Pages (Settings → Pages → main branch)
4
Register — submit a PR to the hub repo adding your URL to data/registry.json
5
Approved — an existing member reviews and merges your PR
6
Live — the hub discovers your manifest on the next hourly crawl. You're in.
