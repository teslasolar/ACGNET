ACG-NET

Decentralized Guild Web — Federated GitHub Pages — P2P Member Sites

ACG-NET is the technical infrastructure layer for the AI Craftspeople Guild. It implements two systems described in the Guild's white papers: a federated network of GitHub Pages where each member owns their own node (ACG-NET), and a permissioned guild blockchain that protects the ethical refusal register (ACG-KCC). The hub is a router, not a server. Your page is yours. The network is ours.
